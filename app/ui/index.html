        📦 手动安装说明（不用一键部署时点开）

        用 Docker Compose 部署 cnk3x/xunlei（推荐 host 网络， 面板默认 http://NAS-IP:2345）：

        services:
  xunlei:
    container_name: xunlei
    image: cnk3x/xunlei:latest
    restart: unless-stopped
    network_mode: host        # bridge 则加 ports: ["2345:2345"]
    cap_add: [SYS_ADMIN, SYS_CHROOT]
    security_opt: ["apparmor=unconfined"]   # 不加会报 mount: permission denied
    environment:
      - XL_UID=1000           # 改成你自己的 UID/GID（通常 1000）
      - XL_GID=1000
      - TZ=Asia/Shanghai
    volumes:
      - /vol1/1000/docker/xunlei/data:/xunlei/data      # 账号/配置，必须持久化
      - /vol1/1000/downloads:/xunlei/downloads          # 下载目录，按需改

        要点：首次打开面板要登录迅雷账号并填内测邀请码「迅雷牛通」； 上方「保存目录」照抄面板里显示的路径（如 /downloads），留空用引擎默认目录； 数据目录 /xunlei/data 必须持久化，否则重装要重新登录。 若容器日志报 mount: permission denied：是宿主安全策略拦了容器内挂载， 按上面补 security_opt；仍不行改用 privileged: true。
